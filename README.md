# KursWork_3_DB

# Использование PostgreSQL

## API_Adapter

- Класс, являющийся наследником класса Abstract_API. Реализует получение данных с помощью
https://nominatim.openstreetmap.org/ и о самолетах в воздушных пространствах этих стран
с сайта https://opensky-network.org/.


## DBManager

- Класс реализует подключение к базе данных PostgreSQL
- Создаёт базу данных, если она не существует
- Создаёт таблицы работодателей и их вакансий
- Заполняет таблицы данными, полученными по API
- Реализует SQL запросы к базе данных для получения данных из таблиц


## config.py

- Считывает параметры подключения к БД из .ini файла

**Содержимое файла конфигурации**

**[postgresql]**
**host=**        - IP адрес сервера СУБД
**user=**        - имя пользователя
**password=**    - пароль
**port=**        - порт для подключения
